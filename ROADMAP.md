# truetomax roadmap

The full list of requirements, so nothing gets lost between versions.

## Purpose
An evolving guiding light: give each day direction, help execute visions, share gifts through aligned action, and find aligned work that makes money sustainably, with no return to a job. The core problems to solve are discipline, direction, and sharing work with the people who connect with it.

## v1 (built)
- [x] Daily affirmation
- [x] Daily passage from *The Creative Act* (from passages you save), a daily question drawn from it, and a journal
- [x] Daily tasks from the weekly rhythm
- [x] Projects with work and goals (track, modify, assign)
- [x] Visions
- [x] Daily task suggestions based on visions; surfacing feasible new ideas
- [x] Creative partner chat; process of elimination (eliminate projects and ideas with reasons; focus review)
- [x] Learns and evolves from everything: moves tracking, suggestion results, long-term memory, weekly learning pass, insights you confirm or reject, rhythm change proposals
- [x] PWA installable on phone; Supabase + Vercel + Claude API
- [x] Theme: muted grays, black and white, minimalist, with organic and experimental touches

## v2
- [ ] **Instagram (truetomax):** the account is Professional as of Oct 19, 2026. Instagram API with Instagram Login (no Facebook Page needed): read posts, reach and engagement so the partner learns which posts land and plans content from it. Needs a Meta developer app with `instagram_business_basic` and `instagram_business_manage_insights`.
- [ ] **Google Calendar:** show today's events on Today and schedule tasks into time blocks.
- [ ] **Google Drive:** attach docs to projects and visions; let the partner read them.
- [ ] **Stripe:** track money coming in from existing products (SourceDart, Intelligent Adjuster). Use a restricted read-only key; pull charges, payouts and subscriptions into an income view and into the partner's context.
- [ ] **Bank:** track deposits from all income sources via a bank aggregator (for example Plaid), read-only. Income becomes a learned signal alongside moves.
- [ ] Morning push notification with the day's affirmation.
